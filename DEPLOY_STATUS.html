DailyTrade Deployment Status

Current Stack

  • Frontend: Vercel
  • Backend API: Render
  • Authentication: Supabase Auth
  • Database: Supabase Postgres

Backend Check

Open this URL to verify Render:

https://dailytrade-backend.onrender.com/health

Expected response:

{"ok":true}

Vercel Setup

Step 1: Import GitHub repo g3834713-boop/trades into Vercel.
Step 2: Use framework preset Other.
Step 3: Leave build command blank and set output directory to ..
Step 4: Deploy, then copy the Vercel production URL.

Supabase Setup

After Vercel deploys, set Supabase Auth URLs:

Site URL: https://your-vercel-domain.vercel.app
Redirect URLs: https://your-vercel-domain.vercel.app/**

Important Note

Do not open pages like /register.html on Render. Render only serves the API, so those requests correctly return 404. Open frontend pages on Vercel.
